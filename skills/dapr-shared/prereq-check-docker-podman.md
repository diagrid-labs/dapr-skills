# Check Docker or Podman

Run `docker info` (on Windows, retry with `powershell -Command "docker info"` if needed). If Docker is unavailable, try `podman info` (on Windows, retry with `powershell -Command "podman info"` if needed). At least one container runtime must be available and running: `docker info` (or `podman info`) must succeed. Run the command exactly as written, without redirects, pipes or `echo $?`: the Bash tool reports a non-zero exit code as a failed command, and that, or an error such as "Cannot connect to the Docker daemon", means the runtime is not running. If neither is available, inform the user they need to install [Docker](https://www.docker.com/products/docker-desktop/) or [Podman](https://podman.io/docs/installation).
